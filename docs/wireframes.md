# ワイヤーフレーム草案（テキストベース）

Phase 0 で作業するための文章レベルのワイヤーフレーム。Solid/Tauri 実装時はこの骨子をもとにコンポーネントを分解する。

## 1. 学習一覧
- 上部: アプリタイトル + 追加ボタン（「学習を作成」）、検索バー、フィルタ（教科、タグ、並び替え）。
- 本体: カードグリッドまたは行リスト。カードにはタイトル、教科/タグ、進捗（正答率や生成済みコンテンツ数）、最終学習日時を表示。
- カードの操作: 詳細を開く、演習に進む、三点メニュー（編集/削除）。

## 2. 学習詳細
- ヘッダー: タイトル、教科/タグ、最終更新、アクション（演習開始・設定・教材追加）。
- タブ: 「一問一答」「練習問題」「要約」「ポッドキャスト」。右上に「+ 生成」ボタン。
- 本体: 各タブで生成済みコンテンツのリストカード。カードには生成日時、短いサマリ、再生成/編集ボタン。空状態は「教材を追加して生成」CTA を表示。

## 3. 演習画面
- ヘッダー: 学習タイトル + 戻るボタン、モード切替（手書き想定/テキスト入力）。
- 左ペイン: 問題文、図・数式用の領域、ヒント/関連資料リンク。ナビゲーション（前/次）。
- 右ペイン: 回答入力（テキストエリア）と AI チャットログ。送信で採点 → フィードバック/解説を表示。スコア/履歴を下部に表示。

## 4. 汎用AIチャット
- レイアウト: 左にコンテキスト/ツールログ、右にチャット。
- 入力欄: 送信 + プリセット指定（教科や温度）。ツール呼び出しが走った場合は左側ログに表示。
- 返信表示: 通常メッセージ + 「学習を作成」や「問題セットを追加」などの CTA ボタン。

## 5. 教材ごとの設定
- ヘッダー: 学習タイトル + 教材一覧（タブまたはセレクト）。
- 左: 教材ファイルのメタ情報とプレビュー（テキスト/サムネイル/音声再生ボタン）。
- 右: 生成設定（難易度、出題数、形式）、AI プリセット選択、再解析ボタン。
- 下部: 教材の管理アクション（差し替え、削除、ダウンロード）。

## 6. 過去教材から新しい学習作成
- ステップ UI: ① 元の学習/教材を選択（検索 + 絞り込み） ② 抽出された要点/提案内容の確認 ③ 新規学習のタイトル・タグ編集。
- 右側でプレビュー: AI が提案する問題セットや要約を確認して取捨選択。
- 完了ボタンで学習一覧に新規カードを追加し、そのまま詳細へ遷移。

## 7. 設定
- セクション分割: AI 設定（モデル、温度、API キー入力）、教科別プリセット編集、バックアップ/エクスポート。
- プリセット編集: 教科リスト + 選択時に system プロンプトと指示テンプレートを編集するフォーム。
- バックアップ: ローカルエクスポート/インポートのボタンと最終バックアップ日時。
