# 進捗記録の方針とログ

## 記録ルール
- 日付・担当・作業内容・所感/課題を箇条書きで残す。
- 「完了済み」「着手中」「ブロック中」を明示する。
- 参照した PR/コミット/チケットがあればリンクやハッシュを記載する。
- 次のアクションを 1〜3 個に絞って書く。
